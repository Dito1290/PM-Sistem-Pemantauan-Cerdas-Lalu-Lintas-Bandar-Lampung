# PM-Sistem-Pemantauan-Cerdas-Lalu-Lintas-Bandar-Lampung
Project management untuk pengembangan Sistem Pemantauan Cerdas Lalu Lintas Berbasis Deep Learning pada Infrastruktur CCTV Kota Bandar Lampung. Project ini digunakan untuk mengelola Product Backlog, Sprint Planning, pembagian tugas tim, implementasi sistem, integrasi, testing, dan evaluasi progres pengembangan.
